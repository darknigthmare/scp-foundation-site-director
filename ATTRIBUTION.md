## Médias

Aucune image, photographie, illustration, vidéo, musique ou piste audio provenant du SCP Wiki n’est incluse dans cette version. Le build emploie uniquement :

- Canvas et formes procédurales ;
- symboles typographiques ;
- CSS original ;
- sons synthétisés au moment de l’exécution avec Web Audio ;
- une icône vectorielle originale et abstraite.

En particulier, aucune ancienne image associée à SCP-173 n’est distribuée.

## Ajouts futurs

Toute personne ajoutant un SCP, conte, Groupe d’intérêt ou média doit :

1. identifier la page et son auteur ;
2. conserver une URL source ;
3. vérifier la compatibilité de la licence ;
4. ajouter l’attribution ici ;
5. distribuer l’adaptation sous une licence compatible ;
6. conserver la preuve de toute autorisation distincte.

Même si le détenteur d’un build possède des licences ou autorisations supplémentaires, cette copie contient des éléments dérivés CC BY-SA et doit conserver les obligations applicables à ces éléments.
